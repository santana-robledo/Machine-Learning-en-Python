# Machine Learning

## Descripción

Este repositorio contiene prácticas, ejercicios y proyectos relacionados con **Machine Learning, Deep Learning y redes neuronales artificiales**. Su objetivo es documentar el aprendizaje teórico y práctico de diferentes algoritmos, técnicas de entrenamiento y métodos de evaluación de modelos de aprendizaje automático.

El contenido abarca desde modelos clásicos de regresión y clasificación hasta arquitecturas de redes neuronales profundas, redes convolucionales y Transformers, utilizando herramientas del ecosistema Python y bibliotecas como Keras y PyTorch.

## Objetivo del repositorio

Desarrollar conocimientos y habilidades para construir, entrenar, evaluar y optimizar modelos de aprendizaje automático, comprendiendo sus fundamentos matemáticos, sus aplicaciones y las decisiones involucradas en su implementación.

## Contenido del repositorio

### 1. Regresión y modelos predictivos

Notebooks relacionados con modelos de regresión utilizados para analizar relaciones entre variables y realizar predicciones.

- Regresión lineal simple.
- Regresión lineal múltiple.
- Árboles de regresión.
- Random Forest para regresión.
- Regresión logística.
- Regularización en modelos de regresión.

### 2. Algoritmos de clasificación

Implementaciones de algoritmos supervisados para asignar categorías o clases a diferentes observaciones.

- K-Nearest Neighbors (KNN).
- Árboles de decisión.
- Random Forest.
- Regresión logística.
- Clasificadores Softmax.
- Clasificación mediante redes neuronales.

### 3. Aprendizaje no supervisado y clustering

Exploración de técnicas de agrupamiento para identificar estructuras y patrones en conjuntos de datos sin etiquetas predefinidas.

- K-Means.
- DBSCAN.
- HDBSCAN.
- Comparación de algoritmos de clustering.
- Evaluación de agrupamientos obtenidos mediante K-Means.

### 4. Evaluación y selección de modelos

Estudio de métodos para medir el desempeño de los modelos y seleccionar configuraciones adecuadas para cada problema.

- Evaluación de modelos de clasificación.
- Evaluación de modelos Random Forest.
- Métricas para modelos de clustering.
- Pipelines de Machine Learning.
- Optimización de hiperparámetros mediante GridSearchCV.

### 5. Fundamentos de redes neuronales artificiales

Implementaciones orientadas a comprender el funcionamiento interno de las redes neuronales y los mecanismos utilizados durante su entrenamiento.

- Propagación hacia adelante (*Forward Propagation*).
- Retropropagación del error (*Backpropagation*).
- Redes neuronales con una o varias capas ocultas.
- Funciones de activación.
- Clasificación de problemas no lineales, como XOR.
- Inicialización de pesos.
- Entropía cruzada y funciones de pérdida.
- Problemas asociados con la inicialización de parámetros.

### 6. Entrenamiento y optimización de redes neuronales

Experimentos enfocados en analizar los factores que influyen en el aprendizaje y la estabilidad de las redes neuronales.

- Inicialización uniforme y Xavier.
- Inicialización con pesos iguales.
- Momentum y sus efectos durante el entrenamiento.
- Dropout para regresión y clasificación.
- Normalización por lotes (*Batch Normalization*).
- Redes neuronales con múltiples capas.
- Uso de `nn.ModuleList()` en PyTorch.
- Comparación de funciones de activación como Sigmoid, Tanh y ReLU.

### 7. Modelos de Deep Learning con Keras

Implementación de modelos de aprendizaje profundo utilizando Keras para abordar problemas de regresión, clasificación y procesamiento de imágenes.

- Modelos de regresión con Keras.
- Modelos de clasificación con Keras.
- Construcción y entrenamiento de redes neuronales.
- Aplicación de técnicas de optimización y regularización.

### 8. Redes neuronales convolucionales

Estudio e implementación de redes neuronales convolucionales (*Convolutional Neural Networks, CNN*) para el procesamiento y la clasificación de imágenes.

- Fundamentos de la convolución.
- Funciones de activación y Max Pooling.
- Múltiples canales de entrada y salida.
- Construcción de redes convolucionales sencillas.
- Clasificación de imágenes pequeñas.
- Batch Normalization en redes convolucionales.
- Clasificación de imágenes de anime.
- Proyecto de clasificación con Fashion-MNIST.

### 9. Transformers y arquitecturas modernas

Introducción a arquitecturas de redes neuronales utilizadas en aplicaciones modernas de inteligencia artificial.

- Implementación de Transformers con Keras.
- Exploración de arquitecturas de aprendizaje profundo.
- Estudio de diferentes componentes y estrategias de entrenamiento.

### 10. Proyectos prácticos

El repositorio también incluye proyectos y ejercicios integradores para aplicar los conocimientos adquiridos.

- Proyecto de práctica de Machine Learning.
- Proyecto final.
- Clasificación de imágenes con Fashion-MNIST.
- Experimentos con redes neuronales y diferentes configuraciones de entrenamiento.

## Herramientas y tecnologías

Las principales herramientas utilizadas o exploradas en este repositorio incluyen:

- **Python:** lenguaje de programación para el desarrollo de modelos.
- **Jupyter Notebook:** entorno interactivo para experimentar, ejecutar código y documentar resultados.
- **NumPy:** operaciones numéricas y manipulación de arreglos.
- **Pandas:** preparación y análisis de datos.
- **Matplotlib:** visualización de datos y resultados.
- **Scikit-learn:** implementación de algoritmos de Machine Learning, evaluación de modelos y búsqueda de hiperparámetros.
- **Keras:** construcción y entrenamiento de redes neuronales.
- **PyTorch:** implementación y experimentación con arquitecturas neuronales.
- **Google Colab:** entorno de ejecución de notebooks en la nube.

*Las bibliotecas específicas pueden variar según el notebook y el proyecto.*

## Organización del repositorio

Los archivos están organizados principalmente en notebooks de Jupyter, numerados para facilitar el seguimiento de los temas y las prácticas.

Cada notebook aborda un concepto, algoritmo, experimento o proyecto específico. En conjunto, permiten recorrer diferentes etapas del desarrollo de modelos de aprendizaje automático, desde los fundamentos de regresión y clasificación hasta técnicas de Deep Learning.
